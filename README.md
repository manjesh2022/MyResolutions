# 🎯 MyResolutions

A feature-rich, dark-themed interactive yearly resolutions and target tracking web application built with HTML, CSS (Tailwind), and JavaScript. Seamlessly manage, categorize, search, filter, and track your yearly goals with built-in JSON backup and restore capabilities.

## ✨ Features

- **Multi-Year Support:** Easily switch between different years (e.g., 2026, 2025) using sleek top navigation tabs.
- **Advanced Filtering & Search:**
  - **Live Search:** Instantly filter targets by keyword.
  - **Category Filter:** Organize by General, Health & Fitness, Learning & Skills, Shopping & Tech, Travel & Trips, and Entertainment.
  - **Status Pills:** Toggle between All, Active, and Done targets.
- **Interactive Management:** Add, edit, check off, or delete resolutions on the fly with local persistence.
- **Data Backup & Restore:** Export your complete resolution database to a JSON file or import backups instantly.
- **Compact Header UI:** Optimized layout saving maximum screen space for your goal list.

## 🛠️ Technologies Used

- HTML5 & CSS3
- Tailwind CSS (Modern Styling & Dark Mode)
- JavaScript (ES6+, LocalStorage API, File Reader API)
- FontAwesome Icons
